# Frontend

The Frontend provides the user interface for the e-commerce platform. It is a React single-page
application (SPA) that communicates with the Backend API.

## Responsibilities

- Render the product catalog
- Handle user interactions
- Manage shopping cart state
- Run the checkout flow

## Features

- Product browsing and search
- Shopping cart management
- User authentication
- Order placement and tracking

## Technology

- React 18 with TypeScript
- Redux Toolkit for state management
- React Router for navigation
- Tailwind CSS for styling
