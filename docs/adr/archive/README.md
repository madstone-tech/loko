# Archived ADRs

Decisions from the 0.x proof of concept that v1 replaced. They are kept as history: each one's
status names the ADR that superseded it. They describe the 0.x model (`loko.toml`, frontmatter,
hand-written D2, the v0 MCP tools) and do not apply to current loko.

| ADR | Superseded by |
|---|---|
| [0002 Token-efficient MCP queries](0002-token-efficient-mcp.md) | [ADR-0014](../0014-hcl-authoring.md): MCP `describe` levels |
| [0003 TOON format support](0003-toon-format.md) | [ADR-0011](../0011-toon-mcp-default.md): TOON as the MCP default |
| [0004 Graph conventions](0004-graph-conventions.md) | [ADR-0012](../0012-hcl-source-of-truth.md): HCL as the source of truth |

Other ADRs from the 0.x period (0001, 0009, 0010, 0011) remain in force and stay in `docs/adr/`.
