# Quickstart: validating ViewModel Renderers

**Feature**: `014-viewmodel-renderers` | **Plan**: [plan.md](plan.md)

These scenarios prove the feature end to end. Each one names the requirement it covers. Command
behaviour is specified in [contracts/cli.md](contracts/cli.md), and file layout and notices in
[contracts/output-layout.md](contracts/output-layout.md).

## Prerequisites

```bash
task build                      # or: go build -o bin/loko .
export PATH="$PWD/bin:$PATH"
FIX=testdata/projects/two-systems   # new fixture: 2 systems, 6 containers, 2 environments, prose, tags
```

No `d2` executable is required, and none should be installed for scenario 6.

---

## 1. Zero-config diagrams (US1, FR-001..002, SC-001)

```bash
rm -rf /tmp/loko-out && loko build -p "$FIX" --out /tmp/loko-out
ls /tmp/loko-out/diagrams
```

**Expect**: `landscape.{d2,svg}`, `system-<name>.{d2,svg}` for each system with containers,
`container-<name>.{d2,svg}` only for containers that have components, and `deployment-<env>.{d2,svg}`
for each environment. No file exists for a system with no containers. Exit code `0`.

## 2. Compile failure leaves output untouched (US1/AC5, FR-024)

```bash
cp -r "$FIX" /tmp/broken && echo 'system "x" { parent = nope.nope }' >> /tmp/broken/main.loko.hcl
loko build -p /tmp/broken --out /tmp/loko-out; echo "exit=$?"
```

**Expect**: diagnostics with file, line and column, `exit=1`, and `/tmp/loko-out` byte-identical to
its state after scenario 1 (check with `diff -r` against a copy).

## 3. Determinism (US3, FR-021, SC-002)

```bash
loko build -p "$FIX" --out /tmp/a && loko build -p "$FIX" --out /tmp/b && diff -r /tmp/a /tmp/b
go test ./cmd/ -run TestBuildDeterministic -count=1
go test ./internal/adapters/hclsource/ -run TestRenderDeterministicDiscoveryOrder -count=1
```

**Expect**: no diff. The second test rebuilds with the source files discovered in reverse order. CI
runs the same test on `ubuntu-latest` and `macos-latest`.

## 4. Notices, pruning, localised change (US3/AC3..5, FR-020, FR-022, FR-023, SC-003, SC-004)

```bash
head -2 /tmp/a/diagrams/landscape.svg /tmp/a/index.html
go test ./cmd/ -run 'TestBuild(Notice|Prune|LocalChange)' -count=1
```

**Expect**: every file carries `Code generated by loko from … DO NOT EDIT.` in its first two lines.
Deleting an element removes its files and only its files. A user file placed in the output directory
survives. Changing one description leaves at least 90% of files byte-unchanged.

## 5. Declared views (US2, FR-003..005)

The `testdata/projects/declared-views` fixture declares include, exclude and tag views, one empty view, and one view
named `landscape`.

```bash
go test ./cmd/ -run TestProjectionGolden/declared-views -count=1
```

**Expect**: the projection JSON matches the golden file. The excluded container is absent, and its
edges terminate at `outside`. The empty view yields `view_empty` and no file. The `landscape` view
yields `view_shadowed`.

## 6. No external process (US6, FR-014, SC-005)

```bash
env -i PATH= HOME="$HOME" "$PWD/bin/loko" build -p "$FIX" --out /tmp/c && ls /tmp/c/diagrams/*.svg
task audit-constitution     # the os/exec ban and the backend-import ban for mcp
```

**Expect**: SVGs are produced with an empty `PATH`, and archcheck reports 0 violations.

## 7. Site navigation and links (US4, FR-025..028, SC-008)

```bash
loko build -p "$FIX" --format html --out /tmp/site && open /tmp/site/index.html
go test ./cmd/ -run TestSiteLinksResolve -count=1
```

**Expect**: the summary says `added svg (required by html)`. Clicking from the landscape through to
a container page shows its prose, its uses and used-by tables, its components and its diagram. An
element with a missing prose file still has a page with a "prose file not found" note. The link
checker reports zero broken links.

## 8. Live preview (US5, FR-029..033, SC-006)

```bash
loko serve -p "$FIX" --port 8123 &
open http://127.0.0.1:8123/
```

1. Edit a `description` and save. The browser updates within 2 s.
2. Introduce a syntax error and save. The page shows the diagnostic with file, line and column.
3. Fix it and save. The page recovers without restarting the command.
4. Touch a non-source file (for example `README.md`) or anything under `dist/`. No rebuild is
   logged.
5. Save three files within 100 ms. One rebuild is logged.

Automated coverage: `go test ./internal/adapters/watch/ ./internal/adapters/devserver/
./internal/core/usecases/ -run 'Test(Poll|Debounce|Serve)' -count=1`.

## 9. Theme override (US7, FR-034..035, SC-009)

```bash
rm -rf /tmp/themed && cp -r "$FIX" /tmp/themed && mkdir -p /tmp/themed/templates
printf '{{define "header"}}<header class="acme">ACME</header>{{end}}' > /tmp/themed/templates/layout.gohtml
loko build -p /tmp/themed --format html --out /tmp/t1 && grep -c acme /tmp/t1/index.html
printf '{{define "nope"}}{{end}}' > /tmp/themed/templates/partials.gohtml
loko build -p /tmp/themed --format html --out /tmp/t2; echo "exit=$?"
```

**Expect**: the first build uses the ACME header and is otherwise identical to the built-in
output. The second fails with `theme_invalid` naming `templates/partials.gohtml` and the block
`nope`, and exits `1`.

## 10. Performance (SC-006)

```bash
go test ./cmd/ -run TestPerformanceBuild -count=1 -v
```

**Expect**: a 1,000-element build in under 10 s, a single-description rebuild through the serve
path in under 2 s, and the 200-container view reported.

```bash
task lint && task test && task audit-constitution
```
