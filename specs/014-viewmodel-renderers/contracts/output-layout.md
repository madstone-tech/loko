# Contract: output layout and generated-file notice

**Feature**: `014-viewmodel-renderers` | **Status**: normative

Paths are relative to the output directory (`--out`, default `dist`) and always use forward
slashes. Every path is produced by `viewmodel.Paths` and never assembled at a call site.

```
dist/
├── .loko-manifest                       # the paths this build owns, sorted (FR-023)
├── index.html                           # html: landscape view and navigation
├── view/<view-id>.html                  # html: one page per view
├── element/<kind>/<name>.html           # html: one page per element (FR-025)
├── assets/style.css                     # html: built-in stylesheet or its override
├── assets/custom.css                    # html: empty unless overridden
├── assets/site.js                       # html: navigation and search (no live-reload code)
├── assets/search-index.js               # html: generated element index for search
├── diagrams/<view-id>.d2                # d2
├── diagrams/<view-id>.svg               # svg
└── md/
    ├── index.md                         # md
    ├── view/<view-id>.md
    └── element/<kind>/<name>.md
```

`<name>` and `<view-id>` are passed through `Segment` (the injective escape in
[research R9](../research.md#r9-file-names-safety-uniqueness-case-collisions-fr-006-fr-028)).
`<kind>` is one of `person`, `system`, `container`, `component` or `external`.

## Ownership

- The tool owns exactly the paths listed in `.loko-manifest`. On rebuild, owned paths absent from
  the new set are deleted, and every other file in `dist/` is left untouched.
- Byte-identical files are not rewritten.
- A build that fails at any point before `Commit` completes leaves `dist/` unchanged.

## Generated-file notice (FR-020)

Text: `Code generated by loko from <sources>. DO NOT EDIT.` Here `<sources>` is the sorted,
`, `-joined list of project-relative `*.loko.hcl` files that contributed to the artifact. For the
site-wide files (`index.html`, `assets/*` and `md/index.md`), it is every source file in the
project.

| Format | Where |
|---|---|
| `.d2` | Line 1: `# Code generated by loko from … DO NOT EDIT.` |
| `.svg` | Immediately after `<?xml …?>`: `<!-- Code generated … -->` |
| `.md` | Line 1: `<!-- Code generated … -->` |
| `.html` | Line 2, after `<!DOCTYPE html>`: `<!-- Code generated … -->` |
| `.css`, `.js` | Line 1: `/* Code generated … */` |
| `.loko-manifest` | Line 1: `# Code generated … DO NOT EDIT.` |

The notice never contains a timestamp, a tool version, a hostname, or an absolute path.

## Determinism (FR-021, FR-022)

- Same compiled input + same theme → same artifact set, byte for byte, on any OS and in any
  file-discovery order.
- Changing one element's description may change only: its own element pages, its parent's element
  pages, the pages and diagrams of views that draw it, and `assets/search-index.js`. The index
  pages list names and kinds only, never descriptions, so they do not change.
